# ops-tools

One typed tool per `bin/` script. Declarations in `tools.json`; `src/index.ts` is the runner. `openclaw.plugin.json` is generated by `pnpm run plugin:build`.

**Add a tool**: executable in `../../bin` (`--help`, `--json` if structured) → `tools.json` entry (`ops_*` name, `command`, `args`, `result.format`, one `parameters` entry per `flag` or `positional`; `optional: true` if it writes) → `pnpm run plugin:build` → list it under Console helpers in the README. A stale manifest fails validation.

**Install**: `pnpm install --frozen-lockfile`. `openclaw` is an uninstalled peer (`autoInstallPeers: false` in `pnpm-workspace.yaml`); link `node_modules/openclaw` to the global install before `plugin:build`.
